# 2026-08-14 V0.2 MVP 交付与体验修复

## 本轮主题

产品体验修复：学习页周看板、活动抽屉交互、成长页调整、工作台收集箱、AI 接口说明。

## 背景

Trellis V0.2 MVP 工程闭环已完成（Checkpoint 0–5，D1 持久化 + 重启恢复验收通过）。用户提出 6 项交互体验问题后，本轮在 `trellis-cleanup` 工作区（C 盘）直接修复，不重做架构。

## 用户指出的 6 项问题与修复

1. **每周学习时间上限只有 6h 太低** → 后端 cap 1200 分钟；前端选项 2/4/6/8/10/12/15/20 小时，默认 6h。
2. **学习页没有真正生成多个任务、不是周看板、时长不贴合选择** → 规划器按容量拆活动：`floor(capacity/60)` 个核心（上限 8），活动链含建立模型/跟随示范/独立练习/复盘校准/验证产出/迁移案例/加深练习/周内综合；学习页周看板 + 容量统计（可用/核心/缓冲/可选）。
3. **活动页交互太少，只有提交证据** → 抽屉增加：步骤勾选、活动笔记、自检（3 项）、证据类型（6 种）、外部链接。
4. **成长页英文节点、看不到分支、调整无交互** → `NODE_TITLE_BY_ID` 中文映射；ai-literacy 相邻分支返回所有其他分支（共同起点视角）；主动调整表单 + 新增 `POST /api/learning/adjustments/propose`（保存为 proposed，仍需确认）。
5. **工作台收集箱和卡片不可交互** → 前端临时收集箱、资源卡"加入收集箱"、工具卡"本周使用"。
6. **AI API / 登录接入不明确** → 工作台 AI 接入状态说明：当前规则 agent，后续 BYOK / 服务端模型。
