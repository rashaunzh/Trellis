# V0.2 第一条学习切片

## 产品结果

- V0.2 PRD 删除“成人自主学习者”伪分类，改为按学习诉求、深度、基础、材料、证据和容量形成路径差异。
- 明确用户确认目标与边界，Trellis 负责完整内容设计，不要求用户逐项设计课程。
- AI 通识 V1 固定六项核心能力、0–3 熟练等级、12–18 小时体量、综合任务与毕业门槛。
- `AGENTS.md` 与新增说明均使用中文；历史归档保持原文。

## 实现结果

- 新增版本化 AI 通识 V1 内容包、来源、诊断题、内容校验和确定性路径算法。
- 新增三张追加式表：诊断、路径提案、路径项目；现有 V0.1 表未修改。
- 新增内容包、诊断草稿/提交、路径确认/拒绝 API；稳定 owner 和确定性 ID 保证重复提交幂等。
- 新增独立中文 `/learn`，支持介绍、诊断、待确认提案、拒绝和已确认路径状态。
- 无模型密钥可运行；没有真实 AI 调用，也没有保存密钥。
