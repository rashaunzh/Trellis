# 2026-08-20 Trellis V0.2：重排本周体验补洞

## 背景

用户要求继续完成 Trellis V0.2。此前 MVP 已有学习 / 成长 / 工作台三功能、证据驱动闭环、产品页、AI API 配置骨架和硬重置入口，但仍存在一个验收风险：旧 D1 状态不会自动体现新的周计划编排。只有“重新设置”会清空所有学习状态，过于重。

## 本次完成

- 新增 `POST /api/learning/replan`。
- 新增 `LearningApplicationService.replanCurrentWeek()`。
- 新增 `LearningStore.clearOpenActivitiesForPlan()`，并实现于 D1 和内存仓储。
- 学习页顶部新增“重排本周”按钮，并保留原“重新设置”按钮。
- 前端新增 `replanCurrentWeek()` API client。
- 新增领域/API 测试：重排本周应保留已接受证据、已验证节点和已产生证据的活动，同时生成新的本周活动。

## 产品规则

“重排本周”是温和调整：

- 保留节点进度；
- 保留所有证据；
- 保留已产生证据的活动，用于追溯；
- 只删除本周 `planned` / `in_progress` 且没有证据的开放活动；
- 重新生成当前周活动；
- 自动写入一条 `activity_replan` 类型、`accepted` 状态的调整记录。

“重新设置”仍是硬清空：

- 清空该用户学习画像、周计划、活动、节点进度、证据和调整记录；
- 回到未诊断起点。
