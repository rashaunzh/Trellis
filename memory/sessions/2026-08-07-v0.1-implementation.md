# Trellis V0.1 实现会话

## 已实现

- 应用品牌和 Metadata 更新为 Trellis。
- 四条主线的长期路线视图，其中学习 8 阶段、求职 6 阶段。
- 进行中、短期启动、长期规划、暂停四列周看板，以及完成、待确认状态。
- 0.5 星 = 15 分钟的预算展示；任务完成后记录实际分钟。
- 动态添加任务，并要求主线、阶段、项目、为什么做、第一步、完成证据和资料链接。
- 任务详情包含路线顺序、边界、前置/卡点、执行步骤、完成标准、证据和实际用时。
- 对象内“与 AI 讨论”：复制最小上下文包，回写结论/分歧/下一步摘要。
- Notebook 测评 6 步项目链路：
  1. 固定对象与资料
  2. 设计 6 道测试题
  3. 建立指标与 Bad Case
  4. 执行并保存证据
  5. 形成结论和产品建议
  6. 发布作品与复盘
- 周复盘增加“安排有效/无效”反馈，并持久化。
- 概念闪卡工作区：官方解释、白话解释、例子、误区、官方来源和熟悉状态；复用 records 表跨设备保存，未来可导出 Anki。
- 工具地图：明确 Trellis、NotebookLM/Gemini、ChatGPT、Codex、Obsidian/Hermes 与 Anki 的职责和回写内容。
- 为学习、求职、商业与想法路线增加阶段入口任务，使长期方向不只停留在标题。
- API 与 D1 模型对齐新状态，同时兼容旧状态并隐藏旧原型示例。
- 新增 GitHub CI 定义和服务端渲染断言。
