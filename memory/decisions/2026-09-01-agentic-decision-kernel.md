# Agentic 决策内核收口

日期：2026-09-01

## 决策

- Trellis 正式学习链统一为：材料理解、课程判断、路线编排、用户确认、学习反馈、调整决策、来源演进。
- D1 是课程、路线、学习状态和决策记录的唯一业务事实源；Mastra 只保存可暂停、恢复和追踪的工作流状态。
- 正式运行时使用 `DecisionRecord` 与 append-only `DecisionEvent`，高影响路线修改必须经用户或管理员确认。
- 正式 Mastra 工作流固定为课程分析、课程编排、学习调整和来源演进四条；普通用户界面不展示内部工作流或模型名称。
- 课程取舍由发布领域图、Course Genome 和确定性约束求解器决定；模型只负责语义候选和长文本增强，不能创造课程、章节或节点。
- 主备模型使用同一结构合同和 blocking Eval；没有模型凭据时，已发布目录、既有路线和确定性学习推进仍可运行。
- 旧 StagePath、Evidence、Adjustment 和作品运行时退出 production 写链；本机兼容验收必须显式启用，下一次稳定发布后再考虑物理删除。
- 来源变化只产生 candidate 和影响报告；发布课程、领域图和既有用户路线都不得被静默覆盖或迁移。

## 约束

- 本轮不扩大到通用学习、聊天助教、向量数据库、课程市场或自动微课。
- 下一轮停止底层架构扩张，直接优化多课程取舍、方案检查和学习恢复体验。
