# Trellis V0.2 自适应学习方向

## 已确认

1. Trellis 长期服务所有学习领域，首期用 AI 通识基础验证通用学习内核。
2. 产品中心是可信领域底图、个性路径、学习陪伴、掌握评估与动态调整，不是任务或目标管理。
3. “找方向”只做学习诉求澄清、范围校验和材料偏科检查，不扩建为职业导航。
4. 采用通用内核 + 版本化领域内容包；首期只建设 AI 通识内容包。
5. 领域底图由 AI 从一手来源起草、人工审核后发布；运行时新资源先进入候选区。
6. 个性路径以能力和掌握证据为锚，课程完成和作品均是证据来源而非最终目的。
7. 学习体验采用混合编排：Trellis 提供桥接微课、诊断、练习、反馈和导师；深度内容保留在外部权威工具。
8. 用户面对一个长期导师。导师在关键节点主动介入，也允许随时召唤。
9. 学习会话默认结构化但可自由跳出；掌握以综合情境任务为主、知识测验为辅。
10. AI 按可见量规评分并给出置信度，用户确认后才形成重要掌握判断。
11. 低风险难度、支架、复习和活动粒度调整可自动执行；改变目标、主路径或核心能力必须确认。
12. 周计划只使用每周总容量，展示核心与可选活动；不做每日排程。
13. 界面与解释使用中文，AI 前沿内容优先引用英文一手来源。
14. 首期单用户验证，但新数据保留用户归属边界；模型接入采用可替换 BYOK。
15. V0.1 数据、证据和生产站点保留并渐进迁移，四主线退居兼容层。

## 首期成功标准

完成初始诊断、首周学习、至少三次学习会话、一次综合情境任务、用户确认的评分、至少一次有证据的路径调整和一次延迟复测；综合任务或延迟复测需要显示掌握提升。

## 仍未进入实现的事项

- AI 通识内容包的具体能力节点、量规与来源目录。
- 数据库迁移细节和 API JSON Schema。
- 首个模型供应商、具体模型和成本限制。
- V0.1 到 V0.2 的逐记录迁移规则。
