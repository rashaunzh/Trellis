# 生产身份与正式工作流运行时

状态：confirmed
日期：2026-08-31

## 已确认决策

- 生产身份使用 ChatGPT 托管身份；浏览器自报 owner 只允许 localhost 开发与验收。
- Mastra 不是待删除展示层，而是正式课程智能工作流运行时。
- 首版 Mastra 内嵌 Cloudflare Worker，使用官方 D1Store 保存工作流快照。
- Trellis D1 业务表继续作为课程、路线、计划、行动、反馈和知识状态的唯一事实来源。
- 内置服务端 OpenAI-compatible 模型执行有限真实基准；无模型时发布基线和确定性规则必须可用。

## 理由

Trellis 需要可靠承载“生成课程方案 → 等待用户确认 → 恢复并激活路线”，同时不能让工作流快照与产品业务状态形成双重真相。内嵌 Worker + D1 的部署形态足以覆盖当前单用户 MVP，不引入独立服务或 Temporal 的额外运维。
