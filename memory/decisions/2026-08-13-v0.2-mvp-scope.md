# V0.2 MVP 不再止于路径确认

## 已确认

1. 新版 MVP 不能只把旧界面换名，也不能在确认路径后停止。
2. 默认首页进入 `/learn` 自适应学习体验；V0.1 数据和 API 保留为兼容层，但旧看板不再是默认入口。
3. MVP 形成连续体验：诊断、路径提案、用户确认、首周编排、结构化学习、情境练习、待复核证据、能力地图、复习评估和来源查看。
4. 首版完整实现第一项能力的学习闭环，其余能力复用相同内容结构并受前置关系约束。
5. 综合任务正式提交、AI 逐维评分、用户确认掌握和延迟复测自动调度仍在下一阶段实现；MVP 必须明确展示这些毕业门槛，而不是伪造已完成能力。
