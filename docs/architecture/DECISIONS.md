# 当前产品与运行决策

本文件整理仍有效的长期取舍。实现状态见[项目状态](../engineering/PROJECT_STATUS.md)，产品范围见[产品契约](../product/TRELLIS_COURSE_INTELLIGENCE_PRODUCT_CONTRACT.md)。旧会话和模型基准数字由 Git 历史追溯，不作为当前验收证据。

## 学习目标与材料的连续组织

Trellis 从目标、可选材料和约束形成有限路线；用户不需要先理解领域图或手工指定每个知识节点。阶段以明确学习结果组织，材料可以是主线、补充、暂缓或排除。用户限定材料范围时，范围外来源不能静默进入计划。

教学主要由外部课程承担。受支持活动提供有限导学、解释、尝试和反馈修订；这更新了早期仅定位/编排的范围，但不扩为完整课程平台或通用聊天首页。陌生材料和只有目录的来源不能伪装成已读正文。

## 身份、业务事实与工作流

生产身份来自可信托管入口；浏览器自报 owner 只用于受限本地开发与验收。D1 业务表是路线、活动、回答、反馈与正式状态的事实源。Mastra 内嵌 Worker，保存暂停/恢复和重试所需的工作流快照。具体理由及兼容规则见 [Mastra 与 D1 ADR](ADR_MASTRA_D1_RESPONSIBILITIES.md)。

当前不引入独立工作流服务，以避免增加身份同步和运维成本。已有兼容实现只有在无依赖、回归覆盖明确后才可删除；旧名称不构成删除依据。

## AI 候选与正式写入

模型提供语义候选；版本化合同、来源检查与确定性约束负责校验。新路线、重要计划变更和来源迁移必须审阅确认；已有记录不能被新候选静默覆盖。DecisionRecord 和追加事件保留决策依据及结果。

没有模型凭据时，已发布内容、既有路线和确定性流程仍可使用。技术/协议失败可以切换备用模型；虚构章节、未知节点和来源不足不能靠备用模型绕过。模型、合同或来源版本改变后重新评测，不沿用历史供应商排名；配置见[模型运行](MODEL_RUNTIME.md)。

## 数据与协作资料

运行数据库、个人偏好和长期个人路线不进入源码仓库。新克隆不依赖这些本机文件；缺失时不虚构用户信息。Git 保留当前规格、关键决策、简短交接和最新交付摘要，其余过程通过历史追溯。公开边界与保留规则见[仓库交付标准](../engineering/REPOSITORY_DELIVERY_STANDARD.md)。
