# Trellis 3 分钟 Demo Script

更新日期：2026-08-30

## 目标

在 3 分钟内讲清 Trellis 的产品差异：不是课程推荐器，也不是打卡工具，而是面向 AI / AI PM 初学者的课程切分、低启动行动和连续周学习记忆。

## 讲稿

### 0:00 - 0:25 问题

AI 学习者现在的问题不是没有课程，而是课程太多。初学者不知道哪段先看、哪些先跳过，也不愿每次学习后写一篇正式总结。Trellis 要做的是把已有内容变成本周最值得推进的几步。

### 0:25 - 0:50 入口

打开 `/learn`，选择 AI PM 入门方向、当前基础、精力状态和每周时间。这里故意不让用户填写一堆复杂维度，因为初学者本来就无法准确描述自己的能力状态。

### 0:50 - 1:20 课程切分

进入 `/workbench`，粘贴一份课程目录或摘要。Trellis 会先判断材料专业性和阶段适配，再切成多个 `courseSlices`：本周必看、后续再看、只作参考、当前跳过。

重点讲一句：系统不是让用户看完整门课，而是明确告诉他本周只看哪段，为什么看，看完回答什么。

### 1:20 - 1:55 本周执行

回到 `/learn`。第一屏只看三件事：本次行动、本周只看、待处理。行动卡绑定具体 slice，预计时间从 30 分钟起步，并按 15 分钟递增。

打开行动抽屉，展示材料片段、概念折叠解释、卡住时缩小策略和轻反馈入口。

### 1:55 - 2:25 轻反馈

提交一条轻反馈：深度选择、随堂测试结果、状态选择或三句话判断。AI PM 入门阶段不默认要求强作品；轻反馈也会进入 evidence / learningOutputs，成为后续复盘依据。

### 2:25 - 2:45 周复盘与下一周

归档本周复盘。Trellis 汇总完成活动、accepted evidence、needs_revision、材料错配和容量变化，然后生成第 2 周计划。切换周后，历史证据和作品版本不会被覆盖。

### 2:45 - 3:00 收束

Trellis 的价值是确定性推进：从内容过载到课程切片，从课程切片到低启动行动，从轻反馈到连续周计划。外部 AI 可以增强解析和解释，但无模型 Key 时核心闭环仍能运行。

## 展示顺序

1. `/learn` 新用户入口。
2. `/workbench` 粘贴课程目录并展示切片统计。
3. `/learn` 第一屏：本次行动、本周只看、待处理。
4. 活动抽屉的轻反馈。
5. 周复盘、周历史和第 2/3 周。
6. README / 架构图作为收尾。
