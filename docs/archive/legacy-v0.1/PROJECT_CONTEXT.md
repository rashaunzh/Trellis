# Project Context — AI Learning OS

> 更新：2026-08-07
> 给新会话的速览：这是什么、为什么存在、现在在哪

## 一句话

AI Learning OS 是面向「零基础转型 AI 产品经理」的**个人学习与项目推进助手**：先管理现实目标与两周行动，再逐步用 AI 诊断缺口、统筹资料、支持项目、验收证据、调整计划。

## 为什么存在

用户（Rashaun，节能降碳咨询工程师）正在从零基础转型 AI 产品经理。他的学习、求职、作品、商业实验和想法分散在表格、聊天、文件与 GitHub 中，需要一个系统来：

- 回答「现在最应该做什么」
- 把学习/项目/求职/内容输出串起来
- 让计划匹配个人时间与能力（不超载）
- 把做的事沉淀成可证明的作品和能力

## 核心产品逻辑

> 一套有长期主线规划、允许自由收集、按周承诺、由 Agent 解释和调整，并能沉淀学习记忆的个人行动系统。

```
现实任务/目标 → 暴露知识缺口 → 按需学习 → 用于项目/面试 → 形成成果与证据 → 复盘更新计划
```

## 四条主线（G/J/B/I，独立存在）

| 主线 | 核心目的 | 典型内容 |
|---|---|---|
| G 学习成长线 | 建立 AI、产品和 Business 能力 | AI 学习路径、LangChain 学习 |
| J 作品与求职线 | 形成作品证据并完成职业转型 | Notebook 测评、企业知识库、JD/简历 |
| B 商业探索线 | 验证内容生产、流量与变现 | X、自媒体、小红书、短视频 |
| I 创新与想法线 | 保存暂不承诺执行的方向 | Learning OS 本身、工具创意 |

商业探索线有独立链路：选题→判断→载体→制作→发布→记录数据→判断栏目/路径，**不依赖其他主线的成果改写**。

## 版本路线（PRD v0.2）

| 版本 | 核心 | 技术 |
|---|---|---|
| V0.1 计划工作台 | 四条线/项目/任务/证据/两周计划/周复盘 | Next.js+TS+Supabase，无 AI |
| V0.2 学习工作台 | 资料/概念/项目关联 | 结构化 Prompt |
| V0.3 项目驱动学习 | 知识缺口+检索+引用 | RAG、Eval |
| V0.4 AI 调度 | 周诊断+建议+初评 | Tool Calling、HITL |
| V0.5 成长与复用 | 能力沉淀、模板复用 | 长期记忆、Skill |

## 当前状态（2026-08-07）

- **阶段**：V0.1 建设期，代码骨架 + 工作区已有，四页未全
- **评分**：65/100（方向真实，核心智能未成立）
- **最该验证**：AI 能否持续生成合理、可解释、可调整的行动计划
- **收敛方向**：两周行动系统（不是宏大平台）

## 红线（不要做）

- 不做课程平台/题库市场/打卡社区
- 不提前拆微服务、不接 IoT、不做大而全 Dashboard
- 不把 Gemini 测评误设为系统主线
- 系统建设每周 ≤1-2 小时，求职与作品优先
