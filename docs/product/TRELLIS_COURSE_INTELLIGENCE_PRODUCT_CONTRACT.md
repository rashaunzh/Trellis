# Trellis Course Intelligence 产品契约

## 产品责任

Trellis 接管学习编排决策：把用户目标和课程集合转化为有范围、有顺序、有依据、有退出条件的个人课程方案，并在学习过程中保持连续状态。

Trellis 不交付更多课程推荐。它必须回答：

- 当前目标真正涉及哪些知识；
- 每门课程覆盖什么、要求什么前置、讲到什么深度；
- 哪门课承担主线，哪些只采用部分章节；
- 哪些内容重复、过深、过时、暂缓或缺失；
- 用户现在从哪一节开始，学到什么程度即可退出；
- 新课程或新版本是否改变现有判断。

## 首个基准场景

输入：

- 目录：`https://www.deeplearning.ai/courses`；
- 目标：以产品判断为目标理解生成式 AI 与 Agent，不以成为 ML 工程师为前置；
- 约束：每周容量有限，不浏览或收藏整个课程目录。

输出必须包含：

1. 每门候选课程的 `Course Genome`；
2. 课程章节到知识节点的映射；
3. `anchor / selected_units / supplement / defer / exclude` 取舍；
4. 每项取舍的来源、理由、置信度；
5. 分阶段的具体课程章节；
6. 每个阶段和课程的退出条件；
7. 当前课程集合无法覆盖的路线缺口。

## AI 与确定性系统的边界

AI 负责开放语义判断：课程解析、同义归一、章节映射、覆盖比较、目标理解和变更影响分析。

确定性系统负责：schema 校验、引用完整性、前置约束、版本、发布门槛、正式用户状态、决策历史和高影响确认。

Trellis 默认提供内置 AI。BYOK 仅用于更高额度、指定模型或私有材料，不解锁基本课程智能。

模型不可用时，已发布的课程索引和路线继续工作；尚未解析的新材料明确降级，不能伪装成同等深度判断。

## MVP 非目标

- 不托管或复制付费课程正文；
- 不建设课程市场；
- 不默认生成自制微课和大量练习；
- 不把作品提交作为初学主线；
- 不在用户界面展示 Agent、Mastra、模型 ID 或 Eval runtime；
- 不在第一轮支持所有学习领域；
- 不用课程热度替代专业性和个人适配判断。

## 产品成功标准

- 用户不需要浏览整个目录即可得到有限课程组合；
- 每个当前采用章节都能追溯到知识节点和来源；
- 路线明确说明采用、暂缓和排除理由；
- 路线包含退出条件，不诱导无限加课；
- 课程集合存在缺口时明确暴露，不伪造完整覆盖；
- 后续学习状态可以改变课程选择，但不能静默改写历史决定。

## 2026-08-31 实现状态

已交付第一条生产形态纵向切片：

- 发布基线包含 10 个来源、30 个课程或专业参考、36 个领域节点；
- `CourseGenome`、章节节点映射、领域图、课程组合和版本影响均有结构化契约；
- D1 迁移 `0013_course_intelligence.sql` 保存来源、快照、图版本、课程版本、章节、映射、课程组合和模型运行记录；
- DeepLearning.AI 总目录会成为决策范围，系统只在其已发布课程中压缩当前组合，无法覆盖的目标保持为缺口；
- `/learn` 已替换固定画像、固定八周路线、前三周动态演示和默认作品入口；
- `/grow` 展示完整领域结构和当前路线投影；`/workbench` 已回归辅助空间；
- 模型不可用时，已发布内容继续工作；未知材料不生成伪专业结论。
- D1 catalog 现在返回完整 `CourseGenome + tags + mappings`，正式编排不再回读代码 baseline；
- 课程确认后的活动保留 curriculum、课程版本、准确章节和 canonical node，旧 `node_id` 仅作为兼容外键；
- 轻反馈写入 `LearningSignal` 与 canonical knowledge state，成长地图直接读取同一状态；
- 课程激活具有 `inactive / activating / active / failed` 状态，失败后可以重试，不会因先写 confirmed 而永久卡死；
- 新材料的模型分析会保存为 candidate，未经过映射与发布检查不会进入正式课程组合；
- 浏览器 BYOK 明文存储已停用，模型增强统一走服务端网关；
- 迁移顺序由 `drizzle/migration-manifest.json` 管理，CI 会在空 SQLite 中执行完整 15 个迁移；
- Next 已升级至 16.3.3，生产依赖没有 high/critical 漏洞。

尚未完成：自动定期抓取、候选内容内部评审台、生产级私有材料解析、真实账号权限、远程 D1 迁移和线上部署。这些不阻断本地课程取舍与连续学习链路，但仍阻断公开生产发布。
