# Trellis V0.2 平台全景（当前实现状态）

> 状态：工程可用 MVP + P0 三件套全部落地（2026-08-20）
> 线上：https://trellis.rashaunzh.workers.dev（Cloudflare Workers + D1）
> 本文件描述"现在能用的平台"，区别于 PRD（目标定义）与 MVP_DELIVERY（交付记录）。

## 一句话定位

输入目标和每周时间，系统生成学习地图与周计划；在真实材料上学习并提交证据，系统评估驱动成长树——不是打卡/记 todo 工具。

## 页面与能力

| 页面 | 能力 |
| --- | --- |
| /product | 产品介绍 |
| /learn | 诊断（目标/时间/偏好）→ 路线提案 → 周计划看板（活动卡片/抽屉/重排/重新设置）→ 证据提交与评估 |
| /grow | 成长树四色（未点亮/成长中/待确认/已验证）、节点详情、跳学验证、确认掌握/纠正 |
| /workbench | 收集箱（链接/笔记/工具，持久化）、AI 接入配置（OpenAI 兼容 base_url/key/model，key 不回显） |

## 核心闭环（全链路可用）

诊断 → 路线 → 周计划 → 活动 → 证据 → 评估 → 节点状态 → 调整建议；"重排本周"只替换无证据活动，保留证据/节点进度/已产生证据的活动；"重新设置"硬清空（保留 AI 配置与收集箱）。

## 与 todo 工具的三个差异机制

1. 证据驱动：活动完成 ≠ 节点验证，只有评估通过的证据点亮成长树。
2. 掌握确认：综合任务评估通过后节点进入"待确认"，用户确认/纠正后才落定；纠正会降级并生成补强建议（系统判断不静默生效，全部可追溯）。
3. 延迟复测：已验证节点到期复核（学习页提醒卡 + 成长页 badge），通过则间隔翻倍（14→28→56 天），失败则降级回成长中。

## 内容与编排

- 内容样本：AI 通识入门（3 模块 7 中文节点），材料引用 Microsoft AI-For-Beginners 真实课程/notebook 链接（sourceRefs 可点击），不复制课程内容只存结构/摘要/引用。
- 周计划：活动 6 类（概念理解/阅读整理/动手实践/小测验/反思总结/综合情境任务 + 复测），按节点模板过滤 + 容量编排（6h → 6 核心 360/360 分钟）；时间选项 3/5/6/8/12/15/20h + 自定义 1-20h。
- 活动抽屉 6 段：为什么学（节点位置/前后置）/学什么（资源卡）/怎么做（步骤勾选）/输出要求/自检/提交证据。

## 已知边界

- 评估为规则版（LLM 评估接口已就绪，配置后可启用）
- 无账号体系（匿名 owner 隔离，换浏览器/清缓存丢状态；ownerId 可伪造，非安全鉴权）
- 国内直连 workers.dev 可能不稳（可绑自定义域名或本地演示兜底）
- 内容包为样本量（7 节点），全量课程映射是深化方向
