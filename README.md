# AI Learning OS

一个以现实目标为中心、渐进增强的个人学习与实践工作台。V0.1 先替代静态学习表格，管理两周计划、项目、任务、证据与周复盘；后续版本再按真实痛点逐步加入资料统筹、RAG、AI 调度与能力复用。

## 当前版本：V0.1 计划工作台

- G / J / B / I 四条长期主线
- 主攻、配套、维持、候选、暂停五类调度角色
- 10 小时基础容量与 2 小时弹性
- Today、Workbench、Projects、Review 四个核心空间
- 完成状态与验收结论分离

V0.1 不做 RAG、Agent、多用户或复杂基础设施。

## 本地运行

```bash
npm install
npm run dev
```
